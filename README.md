# ALLTRADE-LTD — сайт

Одностраничный сайт-презентация ТОО «ALLTRADE-LTD» (СИЗ под ключ для промышленности Казахстана).

## Структура

```
index.html          — вся страница: разметка + инлайн-стили (<style>) + инлайн-скрипты (<script>)
assets/
  favicon.svg
  og-cover.jpg        — превью для мессенджеров/соцсетей (OpenGraph)
  catalog/            — изображения каталога (webp)
    cutout/           — вырезки товаров для карточек категорий (png, прозрачный фон)
  cases/              — фото для блока кейса и команды (webp)
  video-posters/      — постер(ы)
```

Отдельных сборщиков/зависимостей нет — это статический сайт. Логотип встроен инлайн-SVG.

## Как открыть локально

Просто открыть `index.html` в браузере. Либо поднять локальный сервер (удобнее для относительных путей):

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Как редактировать

- Вся разметка, стили и логика — в `index.html`. Секции размечены комментариями
  (`<!-- HERO -->`, `<!-- PRODUCTS -->`, `<!-- VENDING deep -->` и т.д.).
- Стили — в блоке `<style>` в `<head>`. CSS-переменные бренда — в `:root`
  (основной цвет `--brand:#326450`, шрифты Montserrat + IBM Plex Mono).
- Интерактив (каталог, калькулятор, модалки, форма) — в блоке `<script>` внизу.
- Картинки — в `assets/`. Новые товары каталога: добавить webp/png в `assets/catalog/`
  и запись в массив `CATALOG` в скрипте.

## Проверка после правок

- Открыть страницу, прокрутить целиком: все изображения грузятся, нет горизонтальной прокрутки.
- Мобильная ширина (~390px) и десктоп (≥1000px) — вёрстка не ломается.
- Консоль браузера без ошибок.

## Совместная разработка (ветки + PR)

- `main` — стабильная версия.
- Работа ведётся в отдельных ветках: `feature/<кратко>` или `fix/<кратко>`.
- Слияние — через Pull Request с ревью второго участника.

```bash
git checkout -b feature/my-change
# ... правки ...
git add -A && git commit -m "краткое описание"
git push -u origin feature/my-change
# затем открыть Pull Request на GitHub
```

Не коммитить `.DS_Store`, локальные сборки и служебные файлы (см. `.gitignore`).

## Деплой на прод (alltrade-ltd.kz)

Прод-репозиторий: `shanaum/alltrade-ltd-site`. Любой пуш в `main` автоматически:
1. собирает WordPress-тему из `index.html` (`scripts/build_wp_theme.py`);
2. заливает её по FTPS на хостинг PS.KZ (Plesk, тема `alltrade-ltd`);
3. проверяет, что https://alltrade-ltd.kz отвечает и отдаёт свежую тему.

Статус деплоя — вкладка Actions на GitHub. Секреты FTP лежат в настройках репо.
